## 🚀 Quick Start

1. Open `Pastel-Drop-Wallpaper-Download.html` in any browser
2. Pick a drop from the filter tabs
3. Tap a wallpaper to preview
4. Hit download — done!

Or just **[try it live](https://pavnxet.github.io/pastel-drop)** (if hosted)

## 📱 How to Set

1. **Download** — it saves to Photos / Downloads
2. **iPhone:** Photos → Share → Use as Wallpaper
3. **Android:** Gallery → ⋮ → Set as wallpaper
4. Choose **Lock Screen + Home** for the full pastel vibe 🍬

## 🛠️ Tech Stack
